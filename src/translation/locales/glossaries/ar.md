# UAE Arabic commerce glossary

Use these as context-sensitive defaults, not forced word-for-word mappings.

| English concept | Preferred Arabic |
| --- | --- |
| coupon | كوبون or قسيمة خصم |
| coupon code / discount code | كود خصم or رمز خصم |
| promo code | كود ترويجي or رمز ترويجي |
| deal / offer | عرض; use صفقة only when it is natural in context |
| cashback | استرداد نقدي |
| checkout | إتمام الطلب or صفحة الدفع |
| free delivery | توصيل مجاني |
| terms and conditions | الشروط والأحكام |
| valid until | صالح حتى |
| minimum spend | الحد الأدنى للإنفاق |

Keep official Latin-script brand names when the brand does not publish an
established Arabic form. Never translate or reshape coupon codes.
